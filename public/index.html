FAQ

Find the answers you need

How do I get a link to my file?

Upload the file and a CDN link appears under it. Click Copy to put it on your clipboard.

Can I upload more than one file?

Yes. Select or drop several files and each one uploads on its own with its own progress bar.

Can I choose where files are stored?

Yes. Set the Storage Path field, for example media/images, before you upload.

Can I limit the file types?

Yes. Pick Images Only, JavaScript or CSS in File Type. Files that don't match are skipped.
