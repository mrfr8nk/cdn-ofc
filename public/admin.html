API Reference
Base URL:
GET /:filepath
Serve a file via instant jsDelivr CDN redirect. Cached at edge nodes globally.
POST /upload
Upload a file. Body: multipart/form-data with file, path, customName.
GET /api/files
List all files. Returns array of file objects with URL, size, type, and upload date.
DELETE /api/files/:path
Delete a file by its path. Removes from GitHub and the in-memory store.
GET /api/status
CDN health check. Returns file count, total size, file types, uptime, and config.
